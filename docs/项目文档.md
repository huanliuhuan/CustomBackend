## 3. 部署与启动

### 3.1 前提

- Docker Desktop 运行中,且存在容器 `mysql`(localhost:3306,root/123456)
- JDK 8、Maven 3.6+、Node ≥14.18(≤14 需用 Vite 4,本项目已锁定)
- npm 走淘宝镜像(本机已配置 npmmirror)

### 3.2 方式一:一键启动(推荐)

双击根目录 **`启动.bat`**:

1. 检查 Docker/`mysql` 容器,未运行则提示退出
2. 检测库 `admin_base` 不存在时自动执行 `sql/admin_base.sql` 初始化
3. 分别弹出「后端(8081)」「前端(5173)」两个 cmd 窗口
4. 8 秒后自动打开浏览器 `http://localhost:5173`

> ⚠ 两个黑窗口是前后端进程本体,**保持开着**;关掉即停服。
> ⚠ 脚本为全 ASCII 英文提示——cmd 解析含中文的批处理会错位(见 §9)。

### 3.3 方式二:手动

```
# 首次初始化数据库(项目根目录执行,两行分开)
docker cp sql\admin_base.sql mysql:/tmp/admin_base.sql
docker exec mysql sh -c "mysql -uroot -p123456 --default-character-set=utf8mb4 -e 'source /tmp/admin_base.sql'"

# 窗口 1:后端
cd backend
mvn spring-boot:run

# 窗口 2:前端
cd frontend
npm install
npm run dev
```

> ⚠ cmd 里执行命令**不要把 `# 注释` 一起复制**——cmd 不识别注释,vite 会把 `#xxx` 当目录参数导致页面 404。

### 3.4 端口约定

| 端口 | 用途 | 备注 |
| --- | --- | --- |
| 5173 | 前端 vite dev | 被占用时 vite 自动 +1(5174),此时 proxy 仍指向 8081 不受影响 |
| 8081 | 后端 API | 本机 8080 被其他服务常驻占用,故默认 8081;可用 `SERVER_PORT` 环境变量覆盖 |
| 3306 | MySQL(Docker) | 数据挂载 `D:\mysql_data` |

## 4. 数据库设计

库 `admin_base`,13 张表,全部 utf8mb4。**时间约定:DATETIME 一律按 UTC 存储,接口层统一输出北京时间字符串 `yyyy-MM-dd HH:mm:ss`**(详见 §9 时区)。

| 表 | 说明 | 要点 |
| --- | --- | --- |
| sys_dept | 部门(树) | `ancestors` 逗号链(如 `0,1,2`)支撑"本部门及以下"查询与画布布局 |
| sys_user | 用户 | 软删 `del_flag`;`account` 唯一;内置 `admin` 禁删 |
| sys_post | 岗位 | 被用户占用禁删 |
| sys_role | 角色 | `data_scope` 1全部/2自定义/3本部门/4本部门及以下/5仅本人;`builtin=1` 内置角色(超级管理员)自动拥有全部权限、禁删 |
| sys_menu | 菜单 | `type`:M目录/C页面/F按钮;`path` 相对父级;`perm` 权限码;有子级/已授权禁删 |
| sys_user_role / sys_user_post | 用户↔角色/岗位 | 联合主键 |
| sys_role_menu | 角色↔菜单 | 内置超级管理员不写记录(代码层按 builtin 展开) |
| sys_dict_type / sys_dict_data | 字典 | `is_default` 同类型互斥;删类型连带删数据 |
| sys_config | 参数 | `group_name` 分组展示;`val_type` text/switch/select/pass;`builtin=1` 禁删 |
| sys_oper_log | 操作日志 | AOP 自动写;params 中 password 类字段自动 `***` |
| sys_login_log | 登录日志 | 成功/失败都记 |

**种子数据**:酷炫科技集团(3 中心 8 部门)、12 用户、8 岗位、6 角色、41 菜单、3 字典、4 参数;存储过程 `gen_logs` 生成 1400 条登录日志(30 天)与 520 条操作日志(7 天)供图表演示。

**重置演示数据**:重跑 `sql/admin_base.sql` 前,脚本会 drop 全部表重建。

## 5. 权限体系

### 5.1 模型

- **菜单/按钮两级授权**:登录后 `/api/auth/me` 返回该用户可见的 M/C 菜单树与全部权限码集合;前端侧栏按菜单渲染、按钮按 `auth.can(perm)` 显隐,后端 `@RequiresPerm` 逐接口硬校验——前后端同一套权限码
- **超级管理员**(`super_admin`,`builtin=1`):绕过所有鉴权;页面/按钮数按"全部菜单"口径统计
- **数据权限**:用户对角色的 `data_scope` 取最小值(最宽)生效,作用于用户列表查询:

| data_scope | 含义 | SQL 语义 |
| --- | --- | --- |
| 1 | 全部数据 | 不追加条件 |
| 2 | 自定义 | 当前按全部处理(预留) |
| 3 | 本部门 | `u.dept_id = 当前人部门` |
| 4 | 本部门及以下 | 加 `FIND_IN_SET(部门, ancestors)` 子树 |
| 5 | 仅本人 | `u.id = 当前人` |

### 5.2 权限码清单

| 模块 | 权限码 |
| --- | --- |
| 工作台 | `dashboard:view` |
| 用户 | `system:user:list / query / add / edit / remove / resetPwd / assignRole` |
| 角色 | `system:role:list / add / edit / remove / perm` |
| 菜单 | `system:menu:list / add / edit / remove` |
| 部门 | `system:dept:list / add / edit / remove` |
| 岗位 | `system:post:list / add / edit / remove` |
| 字典 | `system:dict:list / add / edit / remove` |
| 参数 | `system:config:list / add / edit / remove` |
| 操作日志 | `monitor:operlog:list / remove` |
| 登录日志 | `monitor:loginlog:list / remove` |
| 代码生成 | `tool:codegen:list` |

## 6. 接口文档

统一响应 `{code, msg, data}`,`code=200` 成功;认证头 `Authorization: Bearer <token>`;401=未登录/过期,403=无权限。分页参数 `page/size`(可选 `kw/status/from/to`),返回 `{total, rows}`。

### 6.1 认证 `/api/auth`(免登录:captcha、login)

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/captcha` | 获取验证码 `{enabled, key, img(base64)}`;enabled 由参数 `sys.account.captchaEnabled` 决定 |
| POST | `/login` | `{account, password, code, key, remember}` → `{token, user, roles, perms, menus}`;remember=true 有效期 168h 否则 12h |
| POST | `/logout` | 注销当前 token(内存会话移除) |
| GET | `/me` | 当前用户信息 + 权限码 + 可见菜单树 |

### 6.2 用户 `/api/system/users`

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| GET | `/` | `system:user:list` | 分页;kw(账号/姓名/手机)、status、deptId(含子树);自动叠加数据权限 |
| GET | `/{id}` | `system:user:list` | 详情(含 roleIds/postIds) |
| POST | `/` | `system:user:add` | 初始密码取参数 `sys.user.initPassword` |
| PUT | `/{id}` | `system:user:edit` | 修改;携带 roleIds/postIds 时同步关联 |
| DELETE | `/` | `system:user:remove` | body 为 id 数组;内置 admin 与当前登录人禁删 |
| PUT | `/{id}/pwd` | `system:user:resetPwd` | `{password}` ≥6 位 |
| PUT | `/{id}/roles` | `system:user:assignRole` | `{roleIds}` 全量覆盖 |

### 6.3 角色 `/api/system/roles`

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| GET | `/` | `system:role:list` | 分页,含 userCount |
| GET | `/all` | — | 下拉全量 |
| GET | `/matrix` | `system:role:list` | 矩阵视图:`{roles, pairs(rid,mid)}` |
| POST / PUT / DELETE | — | `system:role:add / edit / remove` | 内置角色禁删;有用户禁删 |
| GET | `/{id}/menus` | `system:role:list` | 已授权菜单 id;内置角色返回全部 |
| PUT | `/{id}/menus` | `system:role:perm` | `{menuIds}` 全量覆盖 |

### 6.4 菜单 `/api/system/menus`

GET 树(全部)、POST、PUT `/{id}`、DELETE `/{id}`。删除校验:存在子级或已被角色授权则拒绝。

### 6.5 部门 `/api/system/depts`

GET 树(含 userCount)、GET `/{id}/members`、POST、PUT `/{id}`(换父级时自动维护 ancestors 且禁止移入自身子孙)、DELETE `/{id}`(有子级/有用户禁删)。

### 6.6 岗位 `/api/system/posts`

标准分页 CRUD;被用户占用禁删;`GET /all` 供用户表单下拉。

### 6.7 字典 `/api/system/dicts`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 全部类型+各自数据(卡片页数据源) |
| POST / PUT / DELETE | `/type…` | 类型 CRUD;type 标识唯一;删除连带删数据 |
| POST / PUT / DELETE | `/data…` | 数据 CRUD;设默认时同类型互斥 |
| GET | `/map` | `{type: [data]}`(表单下拉数据源) |

### 6.8 参数 `/api/system/configs`

GET 全量(按 group_name 分组返回给前端)、POST、PUT `/{id}`、**PUT `/batch`**(数组 `[{id,value}]`,保存条用)、DELETE `/{id}`(内置禁删)。
关键参数:`sys.user.initPassword`、`sys.account.captchaEnabled`(true/false)、`sys.index.appearance`(light/dark/auto)、`sys.log.retentionDays`。

## 7. 前端功能说明

### 7.1 布局与全局

- 侧栏菜单由后端菜单树渲染(两段路径拼接:`父path/子path`);顶栏:面包屑、搜索框(⌘K)、主题切换、用户下拉
- 路由守卫:无 token → 登录页;有 token 无用户信息先 `fetchMe`(防刷新被误判 403);权限码不匹配 → 403 页
- 主题三来源(优先级):命令面板/顶栏切换 > 参数 `sys.index.appearance`(每次登录读一次)> localStorage 记忆

### 7.2 命令面板(⌘K / Ctrl+K,或点顶栏搜索框)

- 输入即搜:页面(名称/路径/分组)、最近访问、动作(切换外观、问系统)
- 输入 `?` 进入**问系统**:预设四问(谁能删除用户 / 哪些角色没人用 / 哪些用户还没分配角色 / 哪些菜单没有授予任何角色),回车执行并渲染溯源答案
- ↑↓ 选择、↵ 打开、Esc 关闭;`点空白也可收起`

### 7.3 权限溯源星图(角色管理 → 溯源)

三节点对称交互,点任一节点从该节点**散射出明细行**(每行一条生长曲线+流动光点):

| 节点 | 展开 | 行内容 |
| --- | --- | --- |
| 用户 12 | 12 行(双列 6+6) | 头像、姓名、@账号·部门、角色标签(未分配灰色) |
| 角色 6 | 6 行 | ○ 名称、N人持有·M个页面;**点行进阶** |
| 菜单 41→14 行 | 目录/页面 | 名称、权限码、N角色授权 |

角色进阶(第三阶段):选中行升格绿框胶囊 → 从胶囊散射「授权页面」行(名称+权限码+N按钮)→ 右侧详情面板(授予页面大数字+按钮分布迷你柱状图、按钮权限/持有用户/状态、备注、持有用户、可访问页面标签)。
收起:点空白、再点同节点、面包屑逐级、卡片 ×。重播/暂停:重放生长动画 / 冻结。顶部统计卡含闲置角色/孤立菜单(非零琥珀高亮)。

### 7.4 组织画布(部门管理 → 画布)

树形自动布局(SVG 贝塞尔连线+渐变发光+背景星点);点部门:光点从根节点沿路径追过去、左侧详情卡(负责人/联系方式/成员)、支持新增下级/编辑/删除;缩放 ±;另有「表格」视图。

### 7.5 日志页

- 登录日志:5 指标卡(滚动数字)+ 星期×小时热力图(高峰标注)+ 趋势折线 + 明细分页表;按 `login_time desc`
- 操作日志:时间范围 tab + 关键词/结果过滤;行展开显示请求参数 JSON(密码打码);按 `oper_time desc`;勾选批量删除

### 7.6 字典与参数

- 字典:卡片样册(标签预览+三色条),点卡片**原地展开**(邻居自动让位)为 2×2,行内管理字典数据;另有表格视图
- 参数:按 group 分组卡片,控件按 `val_type` 渲染(switch/分段/密码/文本);改动暂存,底部浮出「N 项未保存 · 查看差异 · 放弃 · 保存改动」;保存外观参数即刻切换全站主题

### 7.7 深色模式

## 9. 已知坑与设计约定(重要)

1. **时区链路**:DATETIME 按容器(UTC)写入;JDBC 必须 `serverTimezone=UTC` 原样读取;Jackson `time-zone: GMT+8 + date-format` 输出北京时间字符串。三者缺一即出现"时间晚 8 小时/跨天"。
2. **`启动.bat` 全 ASCII**:cmd 解析含中文的批处理会字节错位、整行断裂;同理 cmd 里**不能复制 `# 注释`**(vite 会把 `#xxx` 当根目录参数 → 全页 404)。
3. **cmd 管道中 `findstr /x` 会因 CRLF 匹配失败**,检测容器名用 `findstr "mysql"`。
4. **Maven 挂在 JRE 上时 Lombok 不生效**:pom 需显式 `maven-compiler-plugin` + `annotationProcessorPaths`(已配置)。
5. **jjwt 0.11.5 的 `signWith(alg, String)` 把字符串当 base64**:密钥含 `-` 直接抛异常;必须 `Keys.hmacShaKeyFor(bytes)`。
6. **Vue scoped 会改写 `@keyframes` 名,但 `:style` 内联 animation 字符串不改**:被内联引用的 keyframes(如 smDraw)必须放**非 scoped** `<style>` 块。
7. **SVG + HTML 百分比混排的可视化,容器必须恒定宽高比**(`aspect-ratio`):否则 SVG `meet` 缩放与 HTML 百分比定位错位(星图装饰点曾飘走);连线的运行时测量也要以画布(而非舞台)为基准。
8. **`<transition mode="out-in">` 偶发卡死**(离开动画不触发即永久空白):已改为双页交叠过渡(离开页绝对定位悬浮)。
9. **刷新被误踢 403**:路由守卫在用户信息加载完成前判断权限所致;守卫内先 `await fetchMe()`(已修)。
10. **菜单 `path` 是相对父级的**:前端拼路由必须 `父path/子path`。
11. **后端进程被强杀会留孤儿 java/node 占端口**:重启前 `netstat -ano | findstr :8081` 找 PID 再 `taskkill /F /PID`。
12. **Docker 停止 → MySQL 停 → 后端 Hikari 挂起**:启动顺序 = Docker Desktop → `docker start mysql` → 后端(会自动重连或重启后恢复)。
13. 大文件导入 MySQL 不要用 `docker exec -i ... < 文件`(会静默截断),用 `docker cp` + `source`。

## 10. 常见问题

**Q:怎么新增一个业务模块?**
① MySQL 建表;② 后端照 `PostController/PostMapper/Post` 三件套复制改名,写接口并挂 `@RequiresPerm`;③ 前端照 `PostView.vue` 复制页面、`router/index.js` 加路由(带 `meta.perm`);④ 「菜单管理」新增 C 页面 + F 按钮记录(权限码与后端一致);⑤ 「角色管理」给目标角色授权。可先用「代码生成」页预览字段骨架。

**Q:忘记 admin 密码?**
`update admin_base.sys_user set password='<新BCrypt>' where account='admin';` 或重跑初始化脚本(会清空全部数据)。

**Q:验证码想关掉?**
参数配置 → 账号自助 → 验证码开关(保存后立即生效);自动化测试时可临时置 false。

**Q:时间显示不对/差 8 小时?**
检查三处:JDBC `serverTimezone=UTC`、`spring.jackson.time-zone: GMT+8`、容器未改动(见 §9.1)。数据库一律存 UTC。

**Q:在线用户数是怎么算的?**
内存会话表中最近 60 分钟有活动的去重用户数;后端重启即清零。

**Q:页面切换偶发空白?**
旧版已修复(out-in 过渡卡死)。若再现,刷新页面并反馈具体操作路径。
